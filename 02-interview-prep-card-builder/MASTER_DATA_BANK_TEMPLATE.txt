HOW TO USE THIS FILE
--------------------------------------------------------------------------------
STANDALONE USERS ONLY: if you're also using the companion resume scanner &
builder project (see /01-resume-scanner-builder in this repo), skip this file
entirely and upload your filled-in DATA_BANK_TEMPLATE.md from that project
here instead. It covers the same ground with a track/accomplishment-ID system
the interview prep builder already knows how to read. Don't maintain two
separate data banks; that's how they drift out of sync with each other.

This is the single source of truth Claude pulls from when building interview
prep cards. The rule that governs everything downstream: if a claim is not in
this file, it does not go on a resume or into a prep card. No inflation, no
fabrication.

Fill in every bracketed section with your own real accomplishments, real
numbers, and real tools. Delete any section that doesn't apply to your field
(e.g. the Sector Translation Table only matters if you move between a
regulated/defense/government context and a commercial one). Leave a section
blank rather than filling it with something you can't defend in a live
conversation.

Rename this file to [YOUR_NAME]_MASTER_DATA_BANK.txt before uploading it to
your Claude Project.
